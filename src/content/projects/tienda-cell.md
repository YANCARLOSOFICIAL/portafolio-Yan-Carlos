- **Monorepo con `docker-compose`**: frontend, API y base de datos se levantan con un solo comando.
- **Flujo de compra completo**: catálogo con filtros multiselección, búsqueda predictiva, carrito y checkout en 3 pasos con envío gratis por umbral.
- **Panel de administración**: productos (con galería), categorías y pedidos.
- **Facturación electrónica real**: precios en COP y facturas ante la DIAN a través de Factus.
- **Backend con estándares**: SQLAlchemy 2 + Alembic (migraciones), Pydantic v2, JWT + bcrypt, Pytest y API documentada con Swagger/Redoc.
