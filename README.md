[![Astro](https://img.shields.io/badge/Astro-5.12-FF5D01?logo=astro)](https://astro.build)
[![React](https://img.shields.io/badge/React-19.1-61DAFB?logo=react)](https://react.dev)

Portafolio personal moderno y responsivo construido con **Astro**, **React** y **Tailwind CSS**. Incluye modo oscuro/claro, animaciones suaves y un diseño profesional optimizado para rendimiento y SEO.

## ✨ Características

- 🎨 **Diseño Moderno**: Interfaz elegante con gradientes y animaciones
- 🌓 **Modo Oscuro/Claro**: Toggle entre temas con transiciones suaves
- ⚡ **Optimizado para Rendimiento**: Astro Islands para carga rápida
- 📱 **Responsive**: Diseño mobile-first que se adapta a todos los dispositivos
- ♿ **Accesible**: ARIA labels y semántica HTML adecuada
- 🔍 **SEO Optimizado**: Meta tags, Open Graph y Twitter Cards
- 💬 **Integración WhatsApp**: Modal para contacto directo
- 🎭 **Animaciones**: Transiciones y efectos visuales atractivos

## 🛠️ Tecnologías

- **[Astro](https://astro.build)** - Framework web moderno
- **[React](https://react.dev)** - Componentes interactivos
- **[Tailwind CSS](https://tailwindcss.com)** - Estilos utilitarios

## Actualización automática de YouTube en Cloudflare Pages

Los videos destacados se actualizan durante cada build usando la API oficial de YouTube.
Para activar la actualización automática:

1. En GitHub abre **Settings → Secrets and variables → Actions**.
2. Crea el secreto `YOUTUBE_API_KEY` con tu clave de Google Cloud.
3. Crea el secreto `YOUTUBE_CHANNEL_ID` con `UCwvO94g5B-22nwJDlKvwdAw`.
4. Verifica que Cloudflare Pages esté conectado a la rama que recibe los cambios, normalmente `master`.

El workflow `.github/workflows/refresh-content.yml` consulta YouTube cada 6 horas, actualiza
`src/data/youtube-videos.json` y hace commit únicamente cuando hay videos nuevos. Ese commit
dispara automáticamente el build de Cloudflare Pages. También se puede lanzar manualmente
desde la pestaña **Actions** de GitHub.
